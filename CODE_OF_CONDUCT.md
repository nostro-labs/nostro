# Contributor Covenant Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and focus on the technical substance. Harassment,
personal attacks, and demeaning comments are not tolerated.

Report unacceptable behaviour through GitHub's private reporting on this repository. Maintainers will
review and respond, and will respect the reporter's privacy.
